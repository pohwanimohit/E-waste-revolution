# ♻️ E-Waste Revolution

A full-stack web platform designed to simplify electronic waste management through digital pickup requests, authentication, and recycling center discovery.

## 🚀 Features

* 🔐 **Authentication** — Firebase-based user authentication.
* 📍 **Waste Pickup Requests** — Submit e-waste collection requests with form validation.
* ♻️ **Recycling Center Lookup** — Find relevant collection centers.
* 📦 **Data Management** — MongoDB-backed storage for user and request data.
* 📱 **Responsive UI** — Modern interface built for different screen sizes.

## 🛠️ Tech Stack

| Frontend     | Backend & Services      |
| ------------ | ----------------------- |
| React.js     | Node.js                 |
| Tailwind CSS | MongoDB                 |
| JavaScript   | Firebase Authentication |

## ⚙️ Getting Started

### Prerequisites

* Node.js and npm
* MongoDB connection
* Firebase project credentials

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/pohwanimohit/E-waste-revolution.git
   cd E-waste-revolution
   ```

2. Install dependencies in the relevant frontend and backend directories:

   ```bash
   npm install
   ```

3. Configure the required environment variables for MongoDB and Firebase.

4. Start the application using the scripts defined in the project's `package.json` files.

> Note: Setup commands may vary depending on the repository structure. Configure credentials locally and never commit secrets.
